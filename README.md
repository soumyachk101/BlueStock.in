# Capstone Project I - Mutual Fund Analytics

Building a full-stack mutual fund analytics platform using AMFI and `mfapi.in` data, covering end-to-end ETL pipelines, a relational star schema data warehouse model, comprehensive risk/performance analytics, and interactive Power BI / Tableau visualization dashboards.

## Project Folder Structure

- **`data/raw`**: Raw CSV datasets, API extractions, and ingested files before processing.
- **`data/processed`**: Cleaned, transformed, and modeled datasets ready for storage and analytical querying.
- **`notebooks/`**: Jupyter notebooks used for exploratory data analysis (EDA), visualization, and data modeling experiments.
- **`sql/`**: Relational schema DDLs, star schema table definitions, views, and analytical SQL queries.
- **`dashboard/`**: Power BI / Tableau dashboard files, visual assets, and reporting templates.
- **`reports/`**: Markdown data quality reports, ETL summaries, and milestone documentation.
